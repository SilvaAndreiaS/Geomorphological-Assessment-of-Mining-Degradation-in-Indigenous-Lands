# Dados do Projeto

Devido ao tamanho e à restrição de segurança territorial, os dados brutos (imagens de satélite, shapefiles de limites e hidrografia) não estão armazenados diretamente neste repositório.

## Fontes Oficiais:
- **USGS / Earth Explorer:** Imagens Landsat 8/9.
- **Copernicus Open Access Hub:** Imagens Sentinel-2.
- **FUNAI / IBGE:** Limites territoriais e malha municipal.
